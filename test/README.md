# Test Inputs

- Any `*.fir` file in this directory is auto-discovered by `make fir-tests` and by the GitHub CI `fir-regression` job.
- repro-usefulreset.fir: Minimized FIR reproducer for GSIM issue #106, used to guard against ConstantAnalysis hangs and OOM regressions.
- executable-grh-split-register-clock.fir: Forces a 256-bit register into two 128-bit split registers, exports executable GRH at `PreCoarsen`, and checks that both write ports retain the original `posedge clock` event. Run it alone with `make test-executable-grh-split-register-clock`.
- executable-grh-async-reset-constant-next.fir: Keeps an async-reset register whose normal update is constant alongside a dynamic-next control register, then checks executable-GRH clock/reset events and the constant-update marker. Run it alone with `make test-executable-grh-async-reset-constant-next`.
- executable-grh-effects.fir: Checks that executable-GRH export omits an optimizer-elided printf, passes a live 128-bit printf operand without narrowing, and literalizes unbound `%d`/`%x` conversions in an assert with an explicit marker. `make test-executable-grh-effects` also runs the focused C++ effect-plan unit, including its unknown-conversion and multi-tree negative cases.
- executable-grh-empty-memory-writer.fir: Keeps a live memory reader while constant analysis removes a constant-false writer, then checks that executable-GRH export preserves the memory/read and emits no write port. Run it alone with `make test-executable-grh-empty-memory-writer`.
- executable-grh-synchronous-memory-address.fir: Checks that an exported synchronous memory read samples the generated address register's destination (the current request), rather than its source (the previous request), avoiding an extra cycle of read latency. Run it alone with `make test-executable-grh-synchronous-memory-address`.
