# Native node evolution

`--trace-node-evolution=PATH` writes a streaming JSONL trace from inside
`splitArray`, including optional array splitting. The default is disabled.
`--trace-input-sha256=HEX` optionally records a caller-verified FIRRTL SHA256;
the producer checks its syntax and labels the identity authority as `caller`.
It does not claim to have computed or verified the digest itself.

The common schema is `wolvrix.node-evolution.v1`. A header names the engine,
graph, pass and `inventoryScope:"all-live"`. Before and after inventories cover
live ordinary Nodes and memory Nodes. Source aggregate and module inventories
are separate namespaces and are not counted as physical Nodes here. Unchanged
IDs have implicit identity, declared by `implicitIdentity:true` in the header.

An entity has `record:"entity"`, `stage:"before"|"after"`, a typed
`ref:{kind:"gsim-node",id,generation:0}`, `physical:{width,signed,shape}`, and
`sources:[{path,role,shape,shapeFieldDepths,projection,width,signed,...}]`.
The source path consists of native FIRRTL tokens; a split member retains its
parent's path and original shape, with fixed source coordinates in `projection`.
Singleton axes removed before this pass remain in that original geometry.
`registerPair` points directly to the native current/next partner. Memory depth
and replacement storage roles are preserved when present.

Widths are the native element width at this boundary, not packed array width.
This pass precedes `InferAllWidth`, so `-1` remains unknown and must not be
treated as proof of source type equality. A trace proves source evolution,
not expression or behavioral equivalence.

Entities carry an exact `structure` with algorithm `native-expression-dag-v1`.
`assignTrees` and `resetTree` give the lvalue/root ENode IDs. `expressions`
serializes the reachable DAG, including each native ENode ID, operation name
and number, type/reset flags, literals, integer parameters, ordered child IDs,
and typed Node/memory references. IDs preserve shared expressions across trees
and physical owners. Node state includes clock, register partner, parent,
memory parameters, member/port lists and external parameters. The old diagnostic
dual 64-bit fingerprint remains available, but replay compares exact JSON.

The header declares `replayContract:"native-field-delta.v1"`. Its reconstruction
scope is the active semantic graph. AST2Graph-only trees, derived adjacency and
scheduling, and code-generation caches are excluded explicitly; they are not
the live assignment graph at this pass boundary.

Events contain a monotonic `seq`, `action`, stable `reason`, typed `before` and
`after` references, and geometry. The pass records native decisions and
rewrites as steps. At successful completion the writer groups steps connected
by shared entity IDs. Each resulting event contains only pass boundary refs,
and every boundary ref is disposed of or generated by at most one event.
Rolled-back and intermediate refs are omitted from those boundary lists.
The `steps` array preserves the actual chronological operations and their
original refs/reasons, including members created within the pass. It can thus
refer to intermediate objects absent from the boundary inventories.

Only a component consisting of one pure split gets `geometry.partition:true`.
Larger rewrite components conservatively set it to false. The constituent
native split steps retain their own `geometry.partition:true`: the parent
disappears and its original Cartesian source coordinates are partitioned among
the new members in native flat-index order. No name matching reconstructs this
relationship.

Reasons are emitted at the decisions or rewrites that produced them:

| Action | Reason | Meaning |
| --- | --- | --- |
| split | `direct_array_self_dependency` | An array Node directly depends on itself. |
| split | `array_dependency_cycle` | An array participates in a dependency cycle. |
| split | `half_constant_array_dependency_cycle` | A half-constant array blocks the traversal through a cycle. |
| split | `static_indexed_array_access` | Optional splitting accepted the assignment and consumer index checks. |
| split | `paired_register_array_split` | Split the next endpoint paired with a selected current array. |
| rewrite | `split_array_reference_rewrite` | An actual expression reference was rewritten; the containing Node ID is unchanged. Geometry identifies the array parent. |
| rewrite | `split_array_shared_expression_rewrite` | A shared native expression changed through another owner; this physical Node keeps its ID but its expression content also changed. |
| rewrite | `register_member_pair_bound` | New current/next members were bound to each other. |
| rewrite | `split_member_name_collision_rename` | An existing scalar is renamed because a newly split member needs its physical name; its original source identity is retained. |
| retain | `dynamic_write_index` | A write uses a variable index. |
| retain | `unsplit_aggregate_input` | A multi-member assignment still depends on an unsplit array input. |
| retain | `dynamic_consumer_index` | A consumer accesses the array with a variable index. |
| retain | `single_array_member` | The physical array contains at most one member. |
| retain | `unsupported_array_node_kind` | Optional splitting excludes this native Node kind. |
| retain | `memory_storage_not_split` | This pass leaves the memory storage Node intact. |
| retain | `array_not_selected_for_optional_split` | An array was not visited as an optional candidate. |

Retain events describe arrays still live at pass completion. A provisional
negative decision for a next endpoint that is subsequently split with its
current partner is not reported as a final retain.

Bundle memory ports share their native address expression. Before rewriting an
array, the pass indexes expression ownership within the actual affected Nodes.
Each mutation records the owners of the exact ENode or ExpTree being changed,
including owners visited after the shared reference was already rewritten. This
evidence comes from native pointers at the mutation, rather than differences
between inventory fingerprints. Ownership indexing is disabled without tracing.

Boundary mutations are native field deltas, rather than references resolved
against the after inventory. Each `mutation` has a monotonic `seq`, `eventSeq`
linking its native evolution component, a typed `ref`, and `action`:

| Action | Payload and precondition |
| --- | --- |
| `create` | `set` is the complete body; the ref must not exist. |
| `update` | `set` contains changed/added top-level fields; `unset` lists removed fields; `expect` gives the exact overwritten/removed old values. |
| `erase` | `expect` is the complete old body; `set` and `unset` are empty. |

Bodies exclude `record`, `stage` and `ref`. Unchanged Nodes inherit their
before bodies. Applying only these deltas to the before inventory reconstructs
the after graph; the independently serialized after inventory is an oracle.
This is pass-boundary replay, not re-execution of every internal native step.
The native writer compares its own serialized before bodies and live boundary
objects to construct deltas. It spools the bodies to disk with an O(Node count)
offset index, so full expression payloads need not remain in memory. A changed,
created or removed Node without an existing native event fails the producer.
It never synthesizes a reason from a detected boundary difference.

The final record is a footer with `complete:true`, `beforeCount`, `afterCount`,
`eventCount`, `mutationCount` and `replayComplete:true`. A missing footer is incomplete evidence. Opening or writing
the requested trace unsuccessfully fails the producer. The writer is reusable
by other native passes; this first integration traces `splitArray` only.

The public writer requires one `inventory("before", ...)`, followed by native
`event(...)` calls, one `inventory("after", ...)`, and one `finish()`. Unknown
stages, repeated inventories or completion, events outside the mutation window,
and completion before both inventories fail the producer. Capture an event's
Node pointers before freeing them; the recorder immediately stores their IDs.

`make test-node-evolution NODE_EVOLUTION_TEST_OUTPUT=<repository-ptmp-path>`
checks exact before-plus-delta reconstruction of every Node, including scalar
rewrites, memory Nodes and shared expression owners, split and retain reasons, original coordinate preservation, current/next
pairing, same-ID rewrites (including shared bundle memory addresses), inventory closure, input identity, rejected invalid
identity and unwritable output. It also compares the normal Init/TopoSort JSON
dumps byte for byte with tracing disabled. Its standalone public API fixture
checks a valid empty trace and rejects twelve invalid lifecycle sequences.
The replay fixture additionally rejects a changed scalar without a native
event, a shared expression mutation recorded for only one physical owner, and
a mutation attributed solely to a retain event.
It replays every Node in the semantic-lineage, memory-inventory and source-
aggregate fixtures and checks exact shared ENode definitions and DAG closure.
